# Clinical Guideline Data Generation Pipeline

This module converts clinical guideline decision tree images into a structured multi-turn question-answering dataset (ClinGuide-MT).

The curated ClinGuide-MT algorithms are **not redistributed**: this pipeline is released so the
construction is reproducible from guideline sources you supply yourself. Stage 1 emits raw vision
output that must be curated by hand into the `TreeNode` schema before Stage 2 will consume it, and
`config.make_client()` is a stub you must implement with your own LLM credentials.
The format example inside the Stage 1 vision prompt is synthetic and does not come from
any specific guideline; it only demonstrates the JSON shape the stage should return.

## Pipeline Overview

```
Stage 1  image_to_json      Images (.jpg/.png) ──Vision──► *_data.json
Stage 2  json_to_questions  *_data.json ─────────────────► *_tree.json
Stage 3  patient_context    *_tree.json  ──"deployment_name"──────────────► *_tree.json  (adds patient_context field)
Stage 4a question_lists     *_data.json ─────────────────► *_question_list.json
Stage 4b question_lists_all *_data.json ─────────────────► *_question_list_all.json
```

## File Structure

```
datagen/
├── config.py           All paths, credentials, and pipeline parameters
├── image_to_json.py    Stage 1 — Vision image-to-JSON conversion
├── tree.py             Tree utilities: anytree visualization, Pydantic schema, trajectory
├── questions.py        Stage 2 — multi-turn question dataset generation
├── patient_context.py  Stage 3 — patient context paragraph generation
├── distractors.py      Stage 4 — question lists and distractor sampling; question summarization
├── __init__.py
├── __main__.py         CLI entry point
└── README.md
```

## Configuration

Edit [`config.py`](config.py) before running. All paths and credentials are defined there.

```python
# Credentials — prefer setting these as environment variables
### Change "deployment_name" and client to specify the model for data generation

# Paths
IMAGE_FOLDER = "/path/to/guideline/images"   # Stage 1 input
DATA_FOLDER  = "/path/to/guideline/data"     # Stages 2–4 input/output

# Parameters
MAX_K         = 4   # max conditions masked per trajectory
N_DISTRACTORS = 20  # distractors per guideline
SEED          = 42
```

## Installation

Install additional dependencies not covered by the root `requirements.txt`:

```bash
pip install openai pillow anytree pydantic tqdm
```

## Usage

```bash
# Run from the clinguide_mt/ directory
# Run the full pipeline
python -m datagen

# Run a single stage
python -m datagen --stage image_to_json
python -m datagen --stage json_to_questions
python -m datagen --stage patient_context
python -m datagen --stage question_lists
python -m datagen --stage question_lists_all
```

Functions can also be imported directly:

```python
from datagen.questions import build_questions
import json

with open("my_guideline_data.json") as f:
    tree = json.load(f)

questions = build_questions(tree, max_k=4)
print(questions.to_dict())
```

## Output File Naming

| File pattern | Generated by | Description |
|---|---|---|
| `<id>_data.json` | Stage 1 | Raw JSON decision tree (GPT output) |
| `<id>_tree.json` | Stage 2 | Multi-turn question dataset |
| `<id>_question_list.json` | Stage 4a | Per-guideline questions + sampled distractors |
| `<id>_question_list_all.json` | Stage 4b | Per-guideline questions + all other guidelines' questions |

## Data Format

### `*_tree.json` (Stage 2 output)

```json
{
  "all_final_outcomes": ["Referral A", "Referral B"],
  "all_final_outcome_type": ["decision"],
  "questions": {
    "1": [
      {
        "final_outcome": "Referral A",
        "final_outcome_type": "decision",
        "k": 1,
        "desired_question": ["Is symptom X present?"],
        "desired_question_answer": ["Yes"],
        "context": {
          "assessment": "Condition Y",
          "Prior condition": "No"
        },
        "patient_context": "A patient presents with..."
      }
    ]
  }
}
```

### `*_question_list.json` (Stage 4a output)

```json
{
  "assessment": "Condition Y",
  "questions": ["Is symptom X present?", "..."],
  "distractors": ["Unrelated question 1", "..."]
}
```
